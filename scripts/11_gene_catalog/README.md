# Stage 11 reference scripts

Stage 11 contains two distinct workflows:

- `11A_NR/`: community non-redundant nucleotide gene catalog, corresponding proteins, Salmon quantification, and abundance matrices
- `11B_MAG/`: unclustered gene and protein catalogs from 374 representative MAGs with gene-to-MAG mapping

The branches use different inputs and Prodigal modes and must not be combined.
